# AURAXIS

این مخزن پروژه‌ی «AURAXIS» است.

## درباره
یک فایل راهنمای پایه برای کمک به خواندن، نصب و اجرای پروژه اضافه شده است. چون ساختار دقیق پروژه و اسکریپت‌های npm/gradle را در این لحظه ندارم، راهنما عمومی نوشته شده و در مرحله‌ی بعد می‌توانم آن را بر اساس فایل‌های واقعی (مثل package.json یا پوشه‌های frontend/android) دقیق‌تر کنم.

## ملزومات
- Node.js (نسخه‌ی پیشنهادی 14 یا جدیدتر)
- npm یا yarn
- برای بخشی که با Kotlin نوشته شده است: JDK، Android Studio یا ابزارهای ساخت مبتنی بر Gradle

## نصب (پایه)
1. مخزن را کلون کنید:
   git clone https://github.com/soheil6913/AURAXIS-X20.git
2. وارد پوشه‌ی پروژه شوید:
   cd AURAXIS-X20

اگر پروژه دارای بخش فرانت‌اند (TypeScript) اس��:
```bash
# در شاخه‌ی مربوط به فرانت‌اند (مثلاً frontend یا web)
cd frontend || cd web || # مسیر مناسب را جایگزین کنید
npm install
npm run build
```

اگر پروژه دارای بخش اندروید/Kotlin است:
- پروژه را با Android Studio باز کنید و اجرا یا بیلد را از آن‌جا انجام دهید.
- یا از خط فرمان با Gradle:
```bash
# در شاخه‌ی پروژه اندروید
./gradlew assembleDebug
```

## اجرا
- فرانت‌اند: دستور اجرای محلی معمولاً `npm start` یا `npm run dev` است.
- اندروید: از Android Studio یا `adb` برای نصب APK استفاده کنید.

## ساختار پیشنهادی فایل‌ها
- `frontend/` یا `web/` — کد TypeScript / JavaScript
- `android/` یا `app/` — کد Kotlin (Android)
- `README.md` — این فایل
